# 🌍 Tourism Expenditure Analysis & Prediction

## About

This project focuses on understanding tourist behavior and building Machine Learning insights from tourism survey data related to visitors traveling to Tanzania.

The goal is to explore travel patterns, package structures, visitor demographics, and financial expenditure in order to extract meaningful insights and support tourism planning and decision-making.

## 🚀 Project Objective

The main objectives of this project are:

1. Perform Exploratory Data Analysis (EDA) on tourism survey data
2. Understand tourist demographics and travel behavior
3. Analyze tourism package composition
4. Study expenditure patterns among visitors
5. Prepare data for potential Machine Learning prediction tasks

## 🔎 Exploratory Data Analysis Highlights

Some important insights discovered during analysis:

#### 🧑‍🤝‍🧑 Tourist Demographics
- Most visitors fall in the 25–44 age group
- Majority of tourists travel alone
- Visitors mainly originate from:
    - USA
    - UK
    - France
#### 🏝️ Tourism Purpose & Activities
Most tourists visit Tanzania for:
- Leisure and holidays
- Wildlife tourism

This highlights the importance of nature-based tourism offerings.

#### ✈️ Travel Arrangements
- Many tourists arrange their own travel
- Travel agents and tour operators are still major information sources
- Word-of-mouth (friends and relatives) plays a significant role

##### 📦 Tourism Package Composition
A large proportion of tourism packages:

1. Do NOT include accommodation
2. Do NOT include food
3. Do NOT include local transport
4. Do NOT include guided tours
5. Do NOT include insurance

This suggests a strong trend toward flexible or minimal travel packages.

#### 💰 Expenditure Patterns
- Total tourist expenditure is positively skewed
- A small number of tourists spend significantly more than others
- Indicates potential for premium tourism targeting
